# 我的世界 C++ 安卓启动器 (MyCraft Android Launcher)

## 👋 关于这个项目
大家好！我是一个 11 岁的独立开发者。我非常喜欢《我的世界》原主机版（LCE），并基于泄露的底层源码，用 C++ 魔改了一个属于自己的版本（加入了变异地形、冰火两重天的物理引擎等）。

为了让没有电脑的玩家也能在手机上玩到，我借助 AI（ChatGPT/Trae）的帮助，基于 **Winlator** 的源码，开发了这个全自动套壳启动器。

## 🚨 遇到的技术死结（求助）
目前启动器已经实现了：首次自动配置环境、自动解压资源、轮播背景图（A.png - G.png）。**但在进入游戏时，遇到了致命闪退。**
